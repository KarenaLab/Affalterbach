## Project - Concrete compressive strength

### About Dataset
This is an educational project about Concrete Compressive Strength and it is a short dataset.

#### Summary
* Number if instances (observations): 1030,
* Number of variables: 8,
* Number of target: 1,

#### Columns names and units
* Cement: Unit: kg per m<sup>3</sup> mixture,
* Blast Furnace Slag: Unit: kg per m<sup>3</sup> mixture,
* Fly Ash: Unit: kg per m<sup>3</sup> mixture,
* Water: Unit: kg per m<sup>3</sup> mixture,
* Superplasticizer: Unit: kg per m<sup>3</sup> mixture,
* Coarse Aggregate: Unit: kg per m<sup>3</sup> mixture,
* Fine Aggregate: Unit: kg per m<sup>3</sup> mixture,
* Age: Unit: days,
* Concrete Compressive Strength [target]: MPa (MegaPascals)
