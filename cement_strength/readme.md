## Project - Concrete compressive strength

### About the Project
This is an educational dataset about **Concrete Compressive Strength**. This is an UCI dataset (link bellow in references).

### Relevant information
* Dataset characteristics: Multivariate
* Associated tasks: Regression
* Size: 1030 x 8
* Target: Compressive Strength in MPa
